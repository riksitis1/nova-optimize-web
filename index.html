SETUP

Get started in three steps

  1. 01

    Check Node.js

    Install a current Node.js LTS release if you need the runtime.

  2. 02

    Open Nexa

    Run Quick Setup and open the Nexa desktop shortcut. For the ZIP, extract it and run Install Nexa.bat.

  3. 03

    Scan and review

    Start with a Windows scan or a game preset. Test a change in the same scene, and use Undo if it makes things worse.
