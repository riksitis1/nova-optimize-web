Safety First

What Nova Optimize refuses to do

Many "PC booster" utilities break Windows updates, trip anti-cheat software, or disable critical security layers. Nova is architected with strict safety boundaries:

Never disables Windows Security

Nova never disables Windows Defender Antivirus, Windows Firewall, SmartScreen, User Account Control (UAC), Core Isolation / HVCI, or Windows Update. Instead, it alerts you if your security protections are turned off.

Never touches game files or memory

Nova never injects DLLs, never reads or writes game process memory, and never modifies game installation directories — keeping it clean alongside kernel anti-cheats (Vanguard, Easy Anti-Cheat, BattlEye, RICOCHET).

Never deletes personal files

Cleanup paths are strictly hardcoded to temporary OS, shader, and browser caches. Personal directories (`Documents`, `Desktop`, `Downloads`, `Pictures`, saved passwords, and browser cookies) are never touched.

Zero telemetry, zero cloud, zero keys

The desktop app binds strictly to 127.0.0.1 with a per-launch random session token. Nothing is uploaded to any server, and there are zero hidden API keys or analytics trackers.

Quick Start

How to install & run in 60 seconds

Nova Optimize runs on standard Node.js (v18 or newer) and Windows PowerShell 5.1 with zero third-party `npm` dependencies.

Step 1

Install Node.js 18+ LTS

If you don't already have Node.js installed, download the official Windows LTS installer from nodejs.org (or let Install Nova.bat install it via Windows winget).

Step 2

Run Setup or Extract ZIP

Run Nova-Optimize-Setup-v1.1.0.cmd to automatically extract to %LOCALAPPDATA%\Programs\Nova-Optimize and create a NOVA Desktop shortcut, or unzip Nova-Optimize-v1.1.0.zip anywhere you like and double-click Install Nova.bat.

Step 3

Create a Restore Point First

When Nova opens, click Restore point in the top-right toolbar (requires Administrator) before applying optimizations so you have both Nova's internal backup and a Windows System Restore checkpoint.

Why does Windows SmartScreen show "Windows protected your PC"?

Because Nova Optimize is 100% free and open-source, we do not pay $400+/year for a commercial EV code-signing certificate. Unlike compiled .exe binaries that hide what they do, every file in Nova Optimize (.bat, .ps1, .js) is plain text that you can open in Notepad and inspect before running. If SmartScreen appears, click More info → Run anyway after verifying the SHA-256 checksum below.
