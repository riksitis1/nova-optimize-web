ARCHITECTURE & SAFETY

Strict operating boundaries

Nexa Optimize is designed to avoid the destructive behaviors common in third-party system tweakers:

Windows Security remains intact

Nexa never disables Windows Defender Antivirus, Windows Firewall, SmartScreen, User Account Control (UAC), Core Isolation / HVCI, or Windows Update. If real-time protection or a firewall profile is off, Nexa flags it as a security warning.

Anti-cheat compatible

Nexa never injects DLLs, never attaches to or reads game process memory, and never modifies game binaries. Game profiles only edit standard user configuration files while the game is closed.

Isolated cache cleanup scope

Cleanup paths are restricted to temporary OS, GPU shader, and browser cache directories. User folders (Documents, Desktop, Downloads, Pictures, saved passwords, and browser sessions) are never scanned.

Loopback-only local server

The desktop interface binds strictly to 127.0.0.1 on an ephemeral port with a per-launch random session token, a 96 MB V8 memory ceiling, and zero external analytics or API keys.

INSTALLATION

Setup and requirements

Nexa Optimize runs on standard Node.js (v18 LTS or newer) and Windows PowerShell 5.1 with zero third-party npm packages.

STEP 01

Install Node.js 18+ LTS

If Node.js is not already installed on your PC, download the Windows LTS installer from nodejs.org (or allow Install Nexa.bat to install it via Windows winget).

STEP 02

Run Setup or Extract Archive

Run Nexa-Optimize-Setup-v1.4.3.cmd to extract to %LOCALAPPDATA%\Programs\Nexa-Optimize and create a NEXA Desktop shortcut, or extract Nexa-Optimize-v1.4.3.zip anywhere and run Install Nexa.bat.

STEP 03

Create a Restore Point

Before applying system-wide changes, click Create restore point in Nexa (requires Administrator) so you have both Nexa's per-setting backup and a Windows System Restore checkpoint.
