CAPABILITIES

Technical scope and modules

Every action in Nova Optimize uses documented Windows Registry keys, PowerShell cmdlets, or standard game configuration files, with automatic pre-change backups stored in data/state.json.

SYSTEM & SCHEDULING

18 Reversible Windows Optimizations

Configure Foreground CPU Quantum Boost (Win32PrioritySeparation), TCP Receive Window Auto-Tuning and Multi-Core RSS, Delivery Optimization P2P limits, Windows Game Mode, Exclusive Fullscreen, Flip-Model presentation, and 1:1 mouse response.

GAME CONFIG PROFILES

Per-Game Video Profiles & Restore

Tune Fortnite (GameUserSettings.ini), Counter-Strike 2 (cs2_video.txt), and Minecraft: Java Edition (options.txt). Select individual settings to apply and restore any single row or the entire file in one click.

PRE-GAME BOOST & RAM

Graceful App Closer & Working-Set Trim

Includes a Pre-Game Boost tool that sends standard WM_CLOSE requests to selected background apps (never force-killing unsaved work), flushes the DNS cache, and trims idle working-set memory via Win32 EmptyWorkingSet.

NETWORK DIAGNOSTICS

Bufferbloat & DNS Resolver Lab

Measure packet jitter across regional endpoints, benchmark public DNS resolvers against uncached domains, and measure ICMP/TCP latency under active download and upload saturation.

CACHE & STARTUP

Temporary Cache & Startup Control

Clears documented temporary shader and browser caches while protecting critical security, input (ctfmon), audio, graphics, and kernel anti-cheat startup entries (such as Riot Vanguard) from accidental disabling.

UPDATES & BACKUPS

SHA-256 Verified In-App Updater

Check for updates and install new releases in place with SHA-256 hash verification and automatic server restart, while preserving your local data/ backup directory and audit history.

ARCHITECTURE & SAFETY

Strict operating boundaries

Nova Optimize is designed to avoid the destructive behaviors common in third-party system tweakers:

Windows Security remains intact

Nova never disables Windows Defender Antivirus, Windows Firewall, SmartScreen, User Account Control (UAC), Core Isolation / HVCI, or Windows Update. If real-time protection or a firewall profile is off, Nova flags it as a security warning.

Anti-cheat compatible

Nova never injects DLLs, never attaches to or reads game process memory, and never modifies game binaries. Game profiles only edit standard user configuration files while the game is closed.

Isolated cache cleanup scope

Cleanup paths are restricted to temporary OS, GPU shader, and browser cache directories. User folders (Documents, Desktop, Downloads, Pictures, saved passwords, and browser sessions) are never scanned.

Loopback-only local server

The desktop interface binds strictly to 127.0.0.1 on an ephemeral port with a per-launch random session token, a 96 MB V8 memory ceiling, and zero external analytics or API keys.

INSTALLATION

Setup and requirements

Nova Optimize runs on standard Node.js (v18 LTS or newer) and Windows PowerShell 5.1 with zero third-party npm packages.

STEP 01

Install Node.js 18+ LTS

If Node.js is not already installed on your PC, download the Windows LTS installer from nodejs.org (or allow Install Nova.bat to install it via Windows winget).

STEP 02

Run Setup or Extract Archive

Run Nova-Optimize-Setup-v1.4.0.cmd to extract to %LOCALAPPDATA%\Programs\Nova-Optimize and create a NOVA Desktop shortcut, or extract Nova-Optimize-v1.4.0.zip anywhere and run Install Nova.bat.

STEP 03

Create a Restore Point

Before applying system-wide changes, click Create restore point in Nova (requires Administrator) so you have both Nova's per-setting backup and a Windows System Restore checkpoint.

Note on Windows SmartScreen ("Windows protected your PC")

Nova Optimize is distributed as an open-source MIT project without a paid commercial EV code-signing certificate. Unlike compiled executables, every file in Nova Optimize (.cmd, .bat, .ps1, .js) is plain text and can be inspected in any text editor before execution. If SmartScreen prompts on first launch, verify the SHA-256 checksum below and select More info → Run anyway.
